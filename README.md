# English Adventure — Prévia de Conteúdo A1

Prévia independente para avaliação; não substitui nem altera o site publicado.

## Conteúdo
- A1.05 — My Home: vocabulário contextualizado, perguntas de compreensão e produção escrita.
- A1.06 — Time: horários, perguntas, situação de atraso e desafio Beat the Clock.
- A1.07 — Daily Routine: amostra do módulo consolidado, pendente de conferência documental com a Planilha-Mãe.

## Como testar
1. Extraia o ZIP.
2. Abra `index.html` no Chrome ou Edge.
3. Alterne entre as três unidades e teste as atividades e botões de áudio.
4. Para hospedar como teste separado, crie um novo site no Netlify e envie a pasta com `index.html`.

## Limitações
- Não altera o site principal nem usa Supabase.
- O progresso é temporário e não é enviado ao professor.
- A leitura usa as vozes do navegador; não há garantia de voz feminina em todos os dispositivos.
- O feedback de texto é demonstrativo, não uma correção completa por IA ou professor.
- Não é a versão final do currículo.
