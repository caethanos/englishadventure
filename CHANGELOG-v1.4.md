# English Adventure Pilot v1.4

## Fixes
- Added a microphone recording card to Days 2–6, matching the speaking mission for each day.
- Added an optional speaking-sample recorder to Day 7 for the teacher check-in.
- Kept the existing Day 1 recording functionality.
- Reused the existing browser recording logic and download playback, so recordings are not automatically uploaded to a server.
- Recording prompts are tailored to the learning goal of each day.

## Important limitation
The browser records and lets the learner replay/download audio. It does not automatically send audio to the teacher or evaluate pronunciation with AI.
